## 为什么写这个博客

从大学接触 NLP，到后来做 RAG 系统的全流程开发，再到用 LangChain 搭建多 Agent 协作系统，这一路踩了不少坑，也积累了一些经验。开这个博客，就是想把这些心得记录下来。

## 博客专注的方向

### 🤖 AI/大模型与 Agent
从 Prompt Engineering 到 Multi-Agent 协作，LLM 的应用正在从"聊聊天"走向"干实事"。我会分享 Agent 系统的架构设计、任务编排、记忆管理等方面的实践。

### 🔍 RAG 检索增强生成
这是我最熟悉的领域。从向量数据库选型、分块策略、混合检索，到端到端延迟优化，踩过的坑都写出来。

### 📝 NLP 自然语言处理
文本分类、NER、语义理解——这些是 AI 应用的基石，也是我进入这个领域的起点。

### 🖥 后端开发
AI 应用不只是模型，还有工程化落地。FastAPI 服务化、数据库优化、系统架构，这些同样重要。
